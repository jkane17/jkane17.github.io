About Me

I'm Jonathan Kane, a software engineer and technical writer. I build tools for Q developers and write about how Q and KDB+ work, from memory allocation and database attributes to compression and the C interface.

My projects include Quill, a terminal IDE for Q, and QLib, a collection of reusable Q modules and a C interface. My articles explore the details behind the code through examples, experiments, and performance measurements.

I'm also interested in Rust, systems programming, and language design.
